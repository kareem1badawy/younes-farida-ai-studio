# Younes & Farida AI Studio

An independent daily video-production repository. It does not modify or trigger the original `younis-farida-daily-video` repository.

See [Arabic setup and configuration](README_AR.md) for the complete instructions.

- 20-second target, vertical 9:16 episodes.
- Egyptian Arabic child-style voices for Younes and Farida.
- Topic history to reduce repeated stories.
- Hugging Face image/video providers and FFmpeg composition.
- GitHub Actions artifacts and daily schedule at 10:00 UTC (1:00 PM Riyadh).
- Optional YouTube upload to the same channel using separately configured OAuth secrets.
- Upload privacy is forced to `Private` for owner review.

Free AI video services have quotas and availability limits. A successful daily cinematic render cannot be guaranteed on free tiers.

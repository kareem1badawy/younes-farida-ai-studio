# مشروع يونس وفريدة المستقل — إنتاج فيديو يومي

هذا مستودع مستقل عن `younis-farida-daily-video`. لا يكتب هذا المشروع إلى المستودع الأصلي ولا يعتمد على تشغيله أو GitHub Actions الخاص به.

## الوظائف
- إنتاج حلقة عربية قصيرة مدتها المستهدفة 20 ثانية، عمودية 9:16.
- شخصيتا يونس وفريدة، مع أصوات مصرية طفولية.
- توليد فكرة وحوار جديدين مع سجل تاريخي لتقليل تكرار الموضوعات.
- توليد صور المشاهد ومقاطع الحركة عبر مزودي Hugging Face المتاحين.
- تجميع الصوت والمشاهد وفحص الملف النهائي.
- حفظ الفيديو والتقرير وبيانات الحلقة كـ GitHub Actions Artifact.
- رفع تلقائي إلى قناة YouTube المرتبطة بأسرار OAuth، مع فرض الخصوصية `Private` حتى تراجعه بنفسك.
- تشغيل يومي مجدول الساعة 1:00 ظهراً بتوقيت الرياض (10:00 UTC).

## صورة الشخصيات
للحفاظ على شكل الشخصيات، يحاول المشروع أولاً استخدام `character.jpg` في جذر هذا المستودع. إذا لم يكن موجوداً، يستخدم رابط الصورة العامة في المستودع الأصلي كمرجع للقراءة فقط. يمكنك لاحقاً رفع نسخة `character.jpg` إلى هذا المستودع الجديد ليصبح مستقلاً حتى في ملف الصورة.

## إعداد الأسرار
من المستودع الجديد افتح:
**Settings → Secrets and variables → Actions**

أضف الأسرار التالية (لا تضع القيم في الملفات أو الرسائل):

| الاسم | الاستخدام |
|---|---|
| `HF_TOKEN` | الوصول إلى Hugging Face |
| `GEMINI_API_KEY` | توليد النصوص/الصور والصوت عند تفعيلها |
| `YT_CLIENT_ID` | بيانات تطبيق YouTube OAuth |
| `YT_CLIENT_SECRET` | سر تطبيق YouTube OAuth |
| `YT_REFRESH_TOKEN` | رمز تحديث OAuth للقناة نفسها |
| `EMAIL_USER` | بريد إرسال التنبيهات (اختياري) |
| `EMAIL_APP_PASSWORD` | كلمة مرور تطبيق البريد (اختياري) |
| `EMAIL_TO` | البريد الذي يستقبل التنبيهات (اختياري) |

يمكن استخدام بيانات OAuth نفسها للقناة ذاتها إذا كان التطبيق والتفويض يسمحان بذلك. أضف الأسرار في هذا المستودع الجديد بشكل مستقل؛ لا يتم نسخ أسرار المستودع الأصلي تلقائياً.

## المتغيرات الاختيارية
من **Settings → Secrets and variables → Actions → Variables**:
- `SPEECH_VIDEO` = `0` افتراضياً لتوفير حصة الفيديو.
- `VEO_ENABLED` = `0`؛ لا تفعّله إلا إذا كنت تقبل خدمة مدفوعة.
- `LOCATION` = `home` أو `forest` أو اتركه فارغاً للتناوب.
- `CHARACTER_IMAGE_URL` = رابط صورة مرجعية بديل إذا لم ترفع `character.jpg`.

## الاختبار والتشغيل اليدوي
1. افتح تبويب **Actions**.
2. اختر **daily-video**.
3. اضغط **Run workflow**.
4. اختر `selftest_offline` أولاً، ثم `selftest_online`، وبعد نجاح الفحوص اختر `run`.

التشغيل المجدول يومياً الساعة 1 ظهراً بتوقيت الرياض. يرفع الفيديو إلى YouTube كـ Private فقط. فشل الرفع لا يفترض أن يلغي إنتاج الفيديو أو ملف الـ Artifact؛ وتُرسل رسالة حالة إذا كانت إعدادات البريد موجودة.

## حدود مهمة
- لا توجد خدمة توليد فيديو سينمائي غير محدودة ومضمونة مجاناً. مساحات Hugging Face المجانية قد تتوقف أو تدخل طوابير أو تغيّر واجهاتها أو تنفد حصتها.
- إذا فشلت خدمات توليد الحركة الحقيقية، لا ينبغي اعتبار تحريك الكاميرا على صورة ثابتة حركة جسدية للشخصيات.
- فحوص تشابه الألوان والحركة مؤشرات تقنية وليست تحققاً بيومترياً من هوية الوجه. راجع الفيديو قبل نشره للعامة.
- يوتيوب يفرض `Private` في سكربت الرفع؛ لا يغيّر المشروع الفيديو إلى Public تلقائياً.

## الاستقلال عن المشروع الأصلي
هذا المستودع له كود وسجل تشغيل وGitHub Actions وأسرار منفصلة. لا يوجد أي push أو تعديل أو workflow dispatch إلى المستودع الأصلي.
